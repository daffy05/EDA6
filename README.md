# Healthcare Data Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on a healthcare dataset using Python. It explores patient information, medical conditions, hospital admissions, billing amounts, and relationships between numerical variables.

## 🎯 Objectives
- Understand the structure of the healthcare dataset.
- Identify and handle missing values.
- Clean and prepare data for analysis.
- Analyze patient admissions and billing amounts.
- Visualize trends and correlations in healthcare data.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## 📂 Project Contents
- `EDA_TASK5.ipynb` – Notebook containing data cleaning, analysis, and visualizations.
- `healthcare_data_for_task.csv` – Healthcare dataset used for analysis.

## 🔍 Analysis Performed
1. Loaded and explored the healthcare dataset.
2. Checked dataset shape, columns, data types, and summary statistics.
3. Identified and handled missing values.
4. Cleaned admission type values.
5. Converted admission and discharge dates into datetime format.
6. Calculated hospital stay duration.
7. Analyzed billing amounts by medical condition.
8. Compared admissions across medical conditions and gender.
9. Visualized admission types and billing distributions.
10. Analyzed monthly patient admissions.
11. Created a correlation matrix and heatmap for numerical variables.
